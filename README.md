# swiftTZ

Первое приложение на SwiftUI: белый экран и чёрный текст `hello world` по центру.

## Код

- [ContentView.swift](SwiftTZCompass/ContentView.swift) — экран приложения.
- [MyApp.swift](SwiftTZCompass/MyApp.swift) — запуск приложения.

## Как запустить

1. Скачайте весь репозиторий.
2. Откройте `SwiftTZCompass.xcodeproj` в Xcode 27 или новее.
3. Выберите схему `SwiftTZCompass` и симулятор iPhone с iOS 27 или новее.
4. Нажмите **Run** (⌘R).

Для запуска на собственном iPhone выберите свою команду в **Signing & Capabilities → Team**.

Проект успешно собран для iOS Simulator в Xcode 27.
