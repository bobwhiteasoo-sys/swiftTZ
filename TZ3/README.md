# Задание 3

Несколько экранов, переходы между ними и взаимодействие приложения с системой.

## Запуск

1. Открыть `TZ3.xcodeproj` в Xcode.
2. Выбрать схему `TZ3` и симулятор iPhone.
3. Нажать Run или `Cmd + R`.

Приложение работает на iOS 16 и новее. Для запуска на своём iPhone нужно выбрать свою команду в Signing & Capabilities.

## Экраны

- Главная — приветствие и переходы на два других экрана.
- О приложении — описание и ещё один переход к системным действиям.
- Системные действия — открытие сайта, копирование текста и меню «Поделиться».

Кнопку «Назад» добавляет `NavigationStack`. Она возвращает на предыдущий экран.

## Файлы

- `TZ3App.swift` — запуск приложения.
- `ContentView.swift` — главный экран и `NavigationStack`.
- `AboutView.swift` — экран с описанием.
- `SystemView.swift` — кнопки для взаимодействия с системой.

## Что используется в коде

- `NavigationLink` открывает другой экран.
- `Button` выполняет код после нажатия.
- `@State` хранит состояние, от которого зависит интерфейс.
- `@Environment(\.openURL)` позволяет открыть сайт в браузере по умолчанию.
- `UIPasteboard.general.string` записывает текст в буфер обмена.
- `ShareLink` открывает системное меню для передачи текста в другое приложение.
- `.alert` показывает сообщение. Знак `$` перед `showAlert` позволяет окну изменить это состояние при закрытии.

Скопированный текст можно вставить, например, в «Заметки». Для открытия сайта нужен интернет. Список приложений в меню «Поделиться» зависит от устройства; в симуляторе он может быть короче.

## Проверка вручную

1. С главного экрана открыть «О приложении» и вернуться кнопкой «Назад».
2. Открыть «Системные действия» с главного экрана и вернуться назад.
3. Открыть «О приложении», оттуда перейти к системным действиям. Кнопка «Назад» должна вернуть сначала к описанию, затем на главную.
4. Нажать «Скопировать текст», закрыть сообщение и вставить текст в другом приложении.
5. Нажать «Поделиться текстом», проверить сообщение в системном меню и закрыть меню.
6. Нажать «Открыть сайт Apple» и проверить, что открылся браузер.
